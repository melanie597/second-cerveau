# Second cerveau

Un espace personnel pour organiser mes notes, idées et connaissances.

## Structure

- Notes de lecture
- Idées et projets
- Références utiles

## Ressources

- [Obsidian](https://obsidian.md) — outil recommandé pour gérer un second cerveau
- [Building a Second Brain](https://www.buildingasecondbrain.com) — méthode PARA

Capturer, organiser et retrouver facilement l'information importante.
